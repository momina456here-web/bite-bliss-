# Bite & Bliss — Restaurant Website

Bite & Bliss is a modern, responsive restaurant website designed to showcase food items and provide a smooth browsing experience.

##  Features
- Responsive and user-friendly design
- Food menu with category filtering
- Search functionality
- Shopping cart interface
- Newsletter subscription UI
- Attractive food images and layout

##  Technologies Used
- HTML5
- CSS3
- JavaScript

##  Project Structure

Bite-Bliss/
├── index.html
├── style.css
├── script.js
└── README.md

##  Getting Started
1. Download or clone this repository.
2. Open the project folder.
3. Run `index.html` in your web browser.

##  Project Purpose
This project demonstrates front-end web development skills, including responsive design, interactive UI components, and JavaScript functionality.

##  Note
This is a front-end demo project. Checkout and newsletter features are not connected to a backend.
